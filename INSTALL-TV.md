# Safe TV installation checklist

1. Build a debug APK first in Android Studio.
2. Do NOT remove the existing TV launcher.
3. Install Match Home TV as a normal app first.
4. Open it from Apps and test D-pad navigation and launching several apps.
5. Press Home. If Android asks which Home app to use, choose Match Home TV only after testing.
6. Initially choose “Just once” if your TV offers that option. Set “Always” only after you are satisfied.
7. If the TV does not offer a launcher chooser, its firmware may restrict third-party launchers; do not disable the stock launcher until device-specific instructions are verified.

To recover on a compatible device, use Settings > Apps > Default apps > Home app and return to the stock launcher.
